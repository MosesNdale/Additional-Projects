# Unity 3D football game
This project was created by using the Unity engine and C# scripts from visual studio code.
Play as a footballer in first person and score a goal or collect balloons.
Download these files to get started, navigate to the 'Contents' folder to open and interact with this project on Unity Engine.
Thanks for reading and using the project, it's free to use.
